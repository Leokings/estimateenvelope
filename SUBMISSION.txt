Title
EstimateEnvelope - Coherence-gated robust estimate envelope

Notes / Description
Built EstimateEnvelope, a reusable GenLayer intelligent contract for coherence-gated robust estimate envelope. Consensus checks whether each numeric range is supported by its rationale; deterministic order statistics seal a median envelope after quorum. One deployment supports multiple independently keyed records and callers. Inputs are public, caller-supplied snapshots; the contract does not automatically fetch or authenticate sources and moves no funds. GenVM lint, strict type checking, 4 direct tests and one five-validator GLSim flow passed. StudioNet verified successful finalized intelligent execution, final-state readback and matching deployed source.
